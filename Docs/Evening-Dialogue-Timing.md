# จังหวะบทสนทนา Evening เทียบ Lawyer Room

ปรับ controller `EveningPoliceDialogue` ให้ใช้การค้างและเปลี่ยนประโยคแบบเดียวกับบทสนทนาโทรศัพท์/ลุงป้องใน Lawyer Room

ค่าที่เทียบจาก Scene ปัจจุบันทั้งสองฉาก:

| ค่า | Lawyer Room | Evening |
|---|---|---|
| เวลาพิมพ์ต่ออักษร | 0.05 วิ | 0.05 วิ |
| ค้างหลังพิมพ์ประโยคพูดครบ | 1 วิ | 1 วิ รวมประโยคสุดท้าย |
| ความเร็วเลื่อนเมื่อขึ้นบรรทัดใหม่ | 18 | 18 |
| ข้อความบรรยาย/ความคิดแบบขึ้นเต็ม | 3 วิ | 3 วิ |
| การเปลี่ยนระหว่างประโยคพูดติดกัน | ใช้เวลาค้างประโยค ไม่มีช่วงจอว่างเพิ่ม | แบบเดียวกัน |

สิ่งที่แก้:

- เดิมประโยคพูดสุดท้ายของตำรวจถูก override ให้ค้าง 3 วินาที ตอนนี้ใช้ `Presentation > Completed Line Hold` (1 วินาที) เหมือนประโยคพูดอื่น
- เดิม `Say()` ซ่อนประโยคทันทีเมื่อพิมพ์และค้างจบ แม้กำลังรอกล้องหันกลับ/เหตุการณ์ผลักตัวผู้เล่น ทำให้จอว่าง ตอนนี้เก็บประโยคเดิมจนประโยคถัดไปเริ่ม หรือเริ่มเปิดตัวเลือก เหมือน `PhoneCallDialogueUI.PlayLine()` ของ Lawyer Room
- ตัวเลือกปิดข้อความพูดก่อนแสดง และคำตอบที่เลือกเริ่มพิมพ์ด้วยการนำเสนอชุดเดียวกับประโยคปกติ
- ข้อความบรรยายแบบขึ้นเต็มค้าง 3 วินาทีเช่นเดิม โดยค่าบรรยายตอนท้ายแสดงชื่อใน Inspector ว่า `Final Narration Hold Seconds` เพื่อแยกจากเวลาค้างบทพูด

ปรับเองได้ที่ `SeatingCanvas/PoliceEncounter` ใน component Evening Police Dialogue: `Presentation` สำหรับบทพูด และ `Full-text narration timing` สำหรับข้อความบรรยาย

ช่วงกล้องหัน/ผลักและเหตุการณ์ของแต่ละทางเลือกยังใช้เวลาของเหตุการณ์นั้นอยู่ จึงอาจเห็นประโยคเดิมค้างนานกว่า 1 วินาทีระหว่างรอเหตุการณ์ ก่อนขึ้นประโยคใหม่

การตรวจ: คอมไพล์ runtime/editor ผ่าน ตรวจ UI อยู่ใต้ SeatingCanvas และตัวอ้างอิงใน Scene ผ่าน ทดสอบ coroutine controller จริงทั้ง 4 ชุดคำตอบ โดยจำลอง UI/กล้อง/ตัวเล่นข้อความเพื่อตรวจลำดับ เวลาค้างที่ส่งให้ตัวเล่น และการซ่อนข้อความ ยังไม่ได้ทดสอบการแสดงภาพ/เสียงใน Unity Play Mode หรือ Build
