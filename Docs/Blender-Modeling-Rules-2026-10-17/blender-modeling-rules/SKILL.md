# กฎการปั้นโมเดลใน Blender

เป้าหมายคือรูปทรงที่ตรง ref ประกอบอย่างสมเหตุผล และมี shading ที่ดี ให้ความสำคัญกับคุณภาพรูปทรงก่อนจำนวน polygon ใช้แนวทางสมจริงสำหรับ hard-surface props เป็นค่าเริ่มต้น และปรับตามสไตล์ที่ผู้ใช้ระบุ

## 1. รักษางานเดิมก่อนแก้

- ระบุไฟล์และเวอร์ชันที่กำลังใช้งาน เก็บงานที่ยังไม่บันทึกก่อนเปิดไฟล์อื่น และแก้ในสำเนาเมื่อปรับงานเดิม
- เก็บชื่อ object, collection, parent, ตำแหน่ง, scale และ pivot ที่ใช้เคลื่อนไหวหรือโต้ตอบ เว้นแต่ผู้ใช้ขอเปลี่ยนส่วนนั้น
- แยกชิ้นที่ต้องถอด เปิด หมุน หรือเปลี่ยนได้ เช่น ประตู สวิตช์ ฟิวส์ และมือจับ ห้าม merge จนทำงานแยกไม่ได้
- ตรวจ shared mesh/material/image ก่อนแก้เฉพาะชิ้น ทำสำเนาข้อมูลเมื่อการแก้จะกระทบ object อื่นโดยไม่ตั้งใจ
- สำหรับงาน UV/material อย่างเดียว เก็บ geometry, silhouette และ transform เดิมไว้ ตรวจเทียบก่อนและหลัง

## 2. อ่าน ref และกำหนดสัดส่วนก่อนลงรายละเอียด

- แยก primary shape, secondary shape, จุดต่อ และรายละเอียดเล็ก ระบุว่ารายละเอียดใดมีผลต่อ silhouette
- ประเมินกว้าง/สูง/ลึก ความหนาผนัง และอัตราส่วนชิ้นส่วน ใช้ภาพหลายมุมหรือ crop จุดสำคัญเมื่อมี
- แยกค่าที่วัดจากไฟล์ ค่าที่อ่านจาก ref และค่าที่สมมุติ ภาพ perspective เพียงมุมเดียวไม่ยืนยันมิติที่มองไม่เห็น
- ใช้หน่วยและ scale เดียวกันทั้งชุด หากเป็น asset เดิมที่ผูกกับเกมแล้ว ให้รักษาขนาดใช้งานเดิม
- ตรวจ blockout ให้ผ่านก่อนเพิ่ม bevel, screw, label หรือรอยสึก หากสัดส่วนหลักผิด ให้แก้รูปทรงก่อน

## 3. สร้างชิ้นงานให้เหมือนของที่ประกอบจริง

- รูปทรงหลักต้องมีหน้าตัดและความหนาที่สอดคล้องกับวัสดุ ตู้ปิดต้องมีผนังและฝาปิดครบตามแบบ
- ตรวจหน้า หลัง ซ้าย ขวา บน ล่าง โดยเฉพาะมุมตู้ ขอบฝา และด้านล่าง อย่าตัดสินว่าปิดสนิทจากภาพหน้าตรงเพียงภาพเดียว
- แยกช่องเปิดที่ตั้งใจออกจากรูที่เกิดจาก modeling error เช่น ช่องลม socket รอยแยกประตู และ clearance สำหรับชิ้นเคลื่อนที่
- เมื่อพบช่องว่าง ให้ตรวจตำแหน่ง ความหนา topology และ normals ก่อน เพิ่มแผ่นปิดเมื่อเป็นส่วนประกอบที่ควรมีตามการก่อสร้างจริง
- สร้าง recess/cutout ให้มีความลึกจริงเมื่อ ref แสดงร่องหรือโพรง ถ้าเป็นแผ่นติดบนผิวจึงค่อยใช้แผ่นนูน
- ท่อและมือจับที่เป็นชิ้นต่อเนื่องควรมี profile และหน้าตัดต่อเนื่อง การซ้อนชิ้นแยกเหมาะกับรอยต่อที่มีอยู่จริง

## 4. วัดรอยต่อ แทนการกะด้วยสายตาอย่างเดียว

- อ้างตำแหน่งจาก face plane, socket, anchor หรือขนาดจริงของชิ้นส่วน แปลงการวัดให้อยู่ใน coordinate space เดียวกัน
- ระบุว่ารอยต่อต้องสัมผัส สอดซ้อน หรือเว้นช่องสำหรับเคลื่อนที่ เลือก tolerance ตามขนาดและความหนาของชิ้นงาน
- Bounding box ที่ซ้อนกันไม่ได้ยืนยันว่าผิวโค้งหรือชิ้นที่หมุนอยู่สัมผัสกันจริง ให้ตรวจผิวบริเวณต่อด้วย
- สายต้องเข้าที่ connector และมี route ที่ต่อเนื่อง ขา/ขายึดต้องรองรับชิ้นหลักได้อย่างสมเหตุผล
- ตรวจการชนและระยะห่างหลัง modifier และขณะชิ้นส่วนหมุนหรือเลื่อน ไม่ตรวจเพียงท่านิ่งหนึ่งตำแหน่ง
- ทำชิ้นซ้ำหนึ่งชุดให้ถูกก่อน duplicate ใช้มิติและ anchor เดียวกันกำหนด spacing

## 5. Topology, normals และ transforms

- แก้ vertices ซ้ำ faces เสื่อมสภาพ ผิวซ้อนโดยไม่ตั้งใจ และ normals กลับด้าน ตรวจ non-manifold ตามชนิดชิ้นงาน
- ชิ้นที่ต้องเป็น solid ต้องมี shell ที่เหมาะสม ส่วน decal หรือแผ่นบางที่ตั้งใจทำเป็น surface ให้ตรวจแยกกัน
- ใช้ topology ที่ควบคุม silhouette และ shading ได้ ไม่เพิ่ม loops บนผิวเรียบโดยไม่มีหน้าที่
- Quad ไม่ใช่เกณฑ์คุณภาพเพียงข้อเดียว ใช้ tris/ngons ได้บนชิ้นแข็งที่ตรวจ triangulation แล้วไม่ทำให้รูปทรงหรือ shading เสีย
- Apply scale เมื่อจำเป็นต่อเครื่องมือและทำได้โดยรักษา pivot, hierarchy, world placement และพฤติกรรมเดิม ตรวจ negative scale และ normals อีกครั้ง
- หลัง Boolean ให้ตรวจร่อง รอยต่อ และ shading ทำความสะอาด geometry ที่ก่อปัญหา ไม่ถือว่า operation สำเร็จเท่ากับโมเดลผ่าน

## 6. Bevel และ shading ต้องสอดคล้องกับรูปทรง

- ใช้ bevel ตามขนาดจริงของขอบและระยะมอง ขอบเล็กอาจใช้ 2–4 segments ส่วนขอบโลหะเด่นระยะใกล้อาจใช้ 4–6 segments ปรับตาม silhouette และงบ
- จำกัด bevel ไม่ให้กินความหนา ลบรายละเอียด หรือทำให้ชิ้นส่วนที่เคยพอดีชนกัน
- Smooth ผิวโค้งและรักษาขอบคม/ระนาบตามแบบ ใช้ flat shading กับผิวที่ตั้งใจแบน
- ใช้ Weighted Normal เมื่อช่วยผิวที่ตรวจจริง ตรวจ modifier order และแสงสะท้อน ไม่ใช้เพื่อกลบ geometry ที่ผิด
- ทรงกระบอกที่เห็นใกล้อาจต้อง 32–64 ด้าน แต่ชิ้นเล็กหรือไกลใช้ต่ำกว่าได้ ตัดสินจาก faceting ของ silhouette
- ใช้ Subdivision กับรูปทรงที่ต้องการความโค้ง และวาง topology รองรับ ไม่ใส่ทุก object เป็นสูตรสำเร็จ

## 7. รายละเอียด วัสดุ และ UV ต้องช่วยอธิบายรูปทรง

- เพิ่ม hinge, bolt, bracket, seam, gland หรือ protective cover ตามหน้าที่และสัดส่วนจริง หลีกเลี่ยงรายละเอียดสุ่มที่ไม่สัมพันธ์กับการประกอบ
- รักษา label และข้อมูลสำคัญเดิม เว้นแต่ผู้ใช้ขอเปลี่ยน
- ตรวจ UV stretch และ texel density ตามขนาดจริง วาง seam ให้เหมาะกับพื้นผิว เช่น ผิวทรงกระบอก
- แยก tiled material UV ออกจาก unique atlas/lightmap UV อย่าเรียก UV ที่ซ้อนสำหรับ tile ว่าพร้อมใช้เป็น lightmap
- วางคราบ รอยขีด และรอยสึกตามการจับใช้งาน ฝุ่น น้ำ หรือความร้อน ไม่ใช้ noise กลบ topology และ shading error
- เลือกความละเอียด texture และรายละเอียดตามระยะมองจริง Procedural material ที่จะส่งข้ามโปรแกรมต้องมีแผน bake/export ที่ตรวจแล้ว

## 8. คุมงบโดยไม่ทำลาย silhouette

- กำหนด polygon budget ตามระยะกล้อง ขนาดบนจอ จำนวนชิ้นซ้ำ และแพลตฟอร์ม ไม่ใช้เลขเดียวกับทุก asset
- ให้ polygon กับโค้งและขอบที่เห็นจริง ลดความหนาแน่นบนผิวแบนและส่วนซ่อนที่ไม่มีประโยชน์
- เก็บชิ้นที่ต้องเคลื่อนไหวแยก และทำ collision แบบง่ายแยกเมื่อจำเป็น
- แยก helper/cutter/วัตถุตรวจงานออกจากชุด export เก็บต้นฉบับที่ยังแก้ได้ไว้

## 9. ตรวจโมเดลจริงก่อนส่ง

- ตรวจ silhouette ใน solid shading และตรวจ normals/ผิวระนาบใน material หรือ rendered preview ด้วยแสงกลางและแสงเฉียง
- ปิด selection outline และซ่อนสิ่งรบกวนเมื่อจำเป็น เพื่อให้เห็น faceting ช่องว่าง และรอยต่อชัด
- เปรียบเทียบก่อน/หลังด้วยมุม ระยะกล้อง และแสงเดียวกัน หากแก้ geometry มาก ให้มี wireframe เพิ่ม
- ตรวจชื่อ hierarchy, pivot, transform และส่วนที่ต้องรักษาเทียบกับ baseline รายงานสิ่งที่เปลี่ยนโดยตั้งใจ
- ทดสอบชิ้นที่ต้องถอด/เปิด/หมุนตลอดช่วงใช้งาน ตรวจรอยต่ออีกครั้งหลัง export และเปิดไฟล์ส่งออกเมื่ออยู่ในขอบเขตงาน
- ภาพสร้างด้วย AI ใช้เป็น ref ได้ ส่วนหลักฐานคุณภาพงานต้องมาจากโมเดลที่ทำจริง
- สรุปไฟล์ที่บันทึก/ส่งออก จำนวน object และ triangle โดยระบุว่าเป็นก่อนหรือหลัง modifier/triangulation วัสดุ texture และข้อที่ยังไม่ได้ตรวจ

เมื่อทำงานด้วย script ให้ rerun แล้วแก้หรือแทนที่ได้เฉพาะสิ่งที่ script เป็นเจ้าของ เก็บ source และสูตรสร้างไว้เมื่อช่วยให้แก้ต่อได้ง่าย ตรวจรูปทรงและผลลัพธ์จริงแทนการเชื่อข้อความ PASS จาก script อย่างเดียว

## งาน prop ที่พับได้และส่งเข้า Unity

เมื่องานมี offset hinge, รูปทรงมุมไม่สมมาตร หรือส่งออก FBX ไป Unity ผ่าน CLI ให้อ่าน [บทเรียน Blender → Unity สำหรับ props](references/blender-unity-props.md) เพิ่มเติม เอกสารนี้บันทึกเฉพาะสิ่งที่ตรวจพบจากงานจริง และควรอัปเดตเมื่อพบปัญหาหรือวิธีแก้ที่ยืนยันผลได้ เก็บรายละเอียดเฉพาะ asset ไว้กับ source/รายงานของ asset นั้น ไม่ยกระดับค่าของงานชิ้นเดียวเป็นกฎสากล

เมื่อต้องแทนโมเดลในฉาก Unity ที่ผู้ใช้เปิดอยู่ ให้อ่าน [การแทน prop ในฉากเดิม](references/unity-scene-prop-replacement.md) เพื่อรักษาวัตถุ จุดอ้างอิง และสถานะงานที่ยังไม่บันทึก

แนวทางนี้คัดจากสกิล Blender hard-surface ที่พัฒนาจากงานจริง โดยปรับให้แชร์ข้ามโปรเจกต์ได้ แนวคิดการอ่าน ref และตรวจ interface บางส่วนอ้างอิง [Blender SuperSkill](https://github.com/powerhouse90/Blender-Superskill/tree/d0c45d5c059bb31d417d7b3d7bc20907fbfea58e) โดย powerhouse90 (MIT)
